\# Enemy FSM 코드 분석



\## 1. 분석 대상



\- 프로젝트: Unity FPS

\- 언어: C#

\- 주요 파일: `Enemy.cs`

\- 관련 파일: `TargetCheck.cs`

\- 주요 기술: FSM, NavMeshAgent, Coroutine



\## 2. 구현 목적



적 캐릭터가 플레이어를 탐지하고, 상황에 따라 이동하거나 공격하는 행동을 상태별로 관리하기 위해 FSM 구조를 사용했습니다.



\## 3. 상태 구성



| 상태 | 역할 |

|---|---|

| Idle | 대상 존재 여부 확인 |

| Reconnaissance | 주변 탐색 및 이동 |

| Run | 탐지한 대상을 추적 |

| Attack | 공격 거리에서 공격 처리 |

| Die | 사망 애니메이션 및 오브젝트 비활성화 |



`Update()`에서 현재 상태에 따라 각 상태 처리 함수를 호출하는 구조입니다.



\## 4. 코드 분석에서 발견한 문제



\### 문제 1. 사망 판정 시점



`Damage()`에서 데미지를 적용하기 전에 체력을 확인하고 있어, 체력이 0 이하로 감소한 순간 사망 상태로 전환되지 않을 수 있습니다.



개선 방향: 데미지 적용 후 체력을 확인하도록 변경합니다.



\### 문제 2. 공격 쿨다운 조건



`UpdateAttack()`은 `isAtkDelay`를 확인하지만 `Atk\_Play()`는 탐색 회전에도 사용하는 `isDelay`를 검사합니다.



개선 방향: 공격 쿨다운을 별도의 변수로 일관되게 관리합니다.



\### 문제 3. 공격 기능 미완성



플레이어에게 데미지를 전달하는 코드가 주석 처리돼 있습니다.



개선 방향: 플레이어의 실제 데미지 처리 인터페이스를 확인하고 공격 기능을 연결합니다.
